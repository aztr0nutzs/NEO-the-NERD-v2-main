# QA Screenshot Archive

This directory is a historical screenshot archive. It contains evidence from multiple older browser, emulator, and device-adjacent QA passes, and some subfolders use names such as `current` from the date they were captured.

For current stabilization truth, use `docs/stabilization/` first, especially the highest numbered phase report. Do not treat screenshots in this directory as proof of the current build unless a stabilization report explicitly cites them for the same date/revision.

New Android runtime receipts should not be committed here unless the task explicitly asks for screenshot/log artifacts. Prefer summarizing command receipts in `docs/stabilization/PHASE*_*.md`.
