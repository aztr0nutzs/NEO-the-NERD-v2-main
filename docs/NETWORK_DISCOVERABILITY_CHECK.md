# Network Discoverability Check

## Required visual proof captures
1. **Main screen visible entry**
   - Capture the `NEURAL_MAP // 3D NETWORK TOPOLOGY` card on Main.
2. **Network screen opened**
   - Capture `NETWORK DISCOVERY + CONTROL` header with adapter/live-demo badges.
3. **3D map obvious/visible**
   - Capture the `3D NETWORK MAP` launcher row and Map tab content container.

## Manual steps
1. Launch app to Main screen.
2. Tap Main card: `NEURAL_MAP // 3D NETWORK TOPOLOGY`.
3. Confirm Network screen opens and shows adapter mode + scan state.
4. Confirm `3D NETWORK MAP` launcher is visible above tabs.
5. Tap launcher if needed; confirm Map tab is active and map container/fallback is visible.
6. On mobile dock, verify `SWIPE DOCK →` hint is visible when dock is horizontally scrollable.
